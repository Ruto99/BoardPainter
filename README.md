# BoardPainter

ブラウザで動く、無料のデジタルスカルプト（3D造形）ツールです。`index.html` を Chrome / Edge で開くだけで使えます（インストール不要・3D表示ライブラリをCDNから読み込むためネット接続が必要）。

## 機能

- **ブラシ（1〜9キー）**: スタンダード / クレイ / 膨らませる / スムーズ / 平らにする / つまむ / 溝 / ムーブ / マスク
- **修飾キー**: `Shift` スムーズ、`Ctrl` マスク、`Alt` 反転、`[` `]` ブラシサイズ
- **表示**: 左右対称（`X`）、ワイヤーフレーム（`W`）、全体表示（`F`）、ペンタブレット筆圧対応
- **ワンクリック処理**: 細分化（`Ctrl+D`）、全体スムーズ、左右対称化、中央に配置、マスク反転／解除
- **書き出し**: OBJ / GLB（ゲーム用）/ STL（3Dプリント用・Z軸上向き・底面Z=0・高さmm指定）
- **読み込み**: OBJ / STL（ドラッグ＆ドロップ可）
- 作業内容はブラウザ（IndexedDB）に自動保存

## 操作

| 操作 | 内容 |
| --- | --- |
| モデル上を左ドラッグ | 造形 |
| 背景を左ドラッグ | 回転 |
| 右ドラッグ | 平行移動 |
| ホイール | ズーム |
| `Ctrl+Z` / `Ctrl+Y` | 元に戻す / やり直し |

## 使用ライブラリ
