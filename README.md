# BoardPainter

無料のデジタルスカルプト（3D造形）**デスクトップアプリ**です。Windows / macOS / Linux で動作し、インストール後はネット接続なしで使えます。

デスクトップ版専用です（ブラウザ版の公開は終了しました）。重い処理は C++ のネイティブモジュールで、CPU のすべてのコアを使って実行します。

## ダウンロード / インストール（Windows）

**[最新版のダウンロードページ（Releases）](https://github.com/Ruto99/BoardPainter/releases/latest)** から、使いたいファイルをダウンロードしてください。

| ファイル | 内容 |
| --- | --- |
| `BoardPainter-Setup-x.y.z.exe` | インストーラー（おすすめ。スタートメニュー・デスクトップにショートカット作成、`.bpp` をダブルクリックで開ける） |
| `BoardPainter-x.y.z-portable.exe` | インストール不要。ダブルクリックでそのまま起動 |

macOS 用（`.dmg`）と Linux 用（`.AppImage`）も同じページにあります。

> 署名していないため、初回起動時に Windows SmartScreen が「WindowsによってPCが保護されました」と表示することがあります。「詳細情報」→「実行」で起動できます。

`.bpp`（プロジェクト）/ `.obj` / `.stl` / `.fbx` / `.glb` ファイルを `BoardPainter.exe` にドラッグ＆ドロップする、または「プログラムから開く」で選ぶと、そのファイルを開いて起動します。インストーラー版では `.bpp` ファイルのダブルクリックで開けます。

## 機能

- **高速処理（ネイティブ C++）**: リメッシュ・ブーリアン・格子状リトポ・ZSphere・文字の立体化・中を空けるの中核処理（ボクセル化・Surface Nets・元の形への吸着）を C++ で実行し、すべての CPU コアを使います（JavaScript 版と同じ結果で、約 5〜10 倍速い）。メモリ上限も広がり、リメッシュの細かさは最大 512 まで指定できます。「表示の設定」で処理エンジンを確認でき、読み込めない環境では自動で JavaScript 版を使います
  - **形に沿った自動リトポ**: 方向場・位置場の計算を C++ で並列実行（グラフ彩色による並列 Gauss-Seidel）。10 万ポリゴンのリトポが約 4 秒（JavaScript 版は約 20 秒）。高い目標ポリゴン数では作業用メッシュも細かくなり、流れが崩れにくくなります
  - **大きなメッシュ（数千万〜1 億ポリゴン級）**: 細分化の処理・当たり判定の木（BVH）・左右対称の対応付けを C++ ／前のレベルからの引き継ぎで高速化（2,163 万ポリゴンへの細分化で使うメモリが約 25% 減少）。プロジェクトの保存・読み込みと自動保存の復元は少しずつ行うので、2GB を超えるファイルも扱えます。彫っている間は、変わった部分だけを GPU に送り、当たり判定の木（BVH）も変わった部分だけ更新します。2,163 万ポリゴンでも 1 回の動きあたり約 30〜40ms で彫れます（以前は時々 0.7 秒ほど止まっていました）。左右対称の対応付けも C++ になり、2,163 万ポリゴンへの細分化は 48 秒 → 20 秒
  - **テクスチャ焼き付け**: レイキャストを C++ で並列実行。4096px の焼き付けが約 2 秒（JavaScript 版は約 20 秒）。テクスチャの大きさに 4096 を追加
- **プロジェクトファイル（.bpp）**: すべてのサブツール・マスク・表示状態・カメラ位置を1ファイルに保存（`Ctrl+S` / `Ctrl+Shift+S`）。圧縮形式で、書き込み途中に落ちても元のファイルは壊れません。保存先のある作業を閉じるときは保存するか確認します
- **サブツール（複数パーツ）**: 球・立方体・円柱・トーラスを追加、OBJ/STLを追加読み込み（OBJ内の複数オブジェクトはそれぞれサブツールに）、複製・削除・並べ替え・名前変更・表示/非表示・ソロ表示、下と結合、マスク部分を分離。ビュー上のダブルクリックでパーツを選択。元に戻すはパーツをまたいで効きます
- **ギズモ（`G`）**: 選択中のサブツールを移動・回転・拡大縮小
- **ポリゴン編集（ZModeler 風・`Q`）**: 低ポリゴンのパーツを面と辺の単位で作り変える。カーソルの下の面・辺・ループが光り、クリック（またはドラッグ）で実行
  - 押し出す / はめ込む（インセット）/ 面を動かす: 面をクリックしてドラッグで量を決める
  - ループを入れる: 辺をクリックすると、四角の帯を一周する辺の輪を入れる（クリックした位置で分割）
  - 面を消す / 穴を閉じる: 面を消して穴にする、穴のふちをクリックして1枚の面でふさぐ
  - 面取り（ベベル）: 辺をクリックすると辺の輪全体を面取り。ドラッグで幅を決める（クリースした辺は面取り後もくっきり）
  - 穴をつなぐ（ブリッジ）: 2つの穴のふちを順にクリックすると、四角の帯でつなぐ
  - クリース: 辺をクリックで辺の輪にクリースを付ける／外す。「角の辺をクリース」で 30° 以上の角をまとめて指定。クリースした辺は細分化しても丸くならない（細分化レベルにも引き継ぎ、プロジェクトに保存）
  - なめらか表示（ダイナミック細分化）: 低ポリゴンのまま、細分化 1〜3 回分の仕上がりを表示しながら作業。「なめらか表示を細分化レベルにする」で確定
  - 対象は「ポリゴン1枚」か「つながった平らな面」（箱の一面をまとめて押し出す等）。三角形のパーツは自動で四角にまとめ、色・マスク・ポリグループも引き継ぎます。細分化レベルがないパーツで使えます
- **細分化レベル**: `Ctrl+D` でレベルを追加、`D` / `Shift+D` で上げ下げ。低いレベルで大きな形を直しても高いレベルの細部が付いてくる（細部は各頂点のローカル座標で保持）。高いレベルで彫った内容は低いレベルにも反映。上/下のレベルの削除、レベルをまたいだ元に戻す、プロジェクトへの保存に対応。細分化できる上限は PC のメモリで決まり、64GB 以上なら約 1 億ポリゴン、32GB 以上は 5,000 万、16GB 以上は 2,800 万（8GB 以上は 800 万、それ未満は 300 万）。数千万ポリゴンでも、彫った所だけを元に戻す用に記録し（1 ストロークあたり数 MB）、元に戻す履歴はメモリの 1/4 までに収めます
- **自動リトポ**: 目標ポリゴン数を指定して四角ポリゴン主体のメッシュを新しいサブツールとして作成（OBJ には四角のまま書き出し、ワイヤー表示も四角）。結果は常に穴・重なり・裏返りのない閉じたメッシュになるよう、抽出後に修復（穴埋め・面の向きの統一・折れ返った面の統合）します
  - 「形に沿う」: 面の向きに沿って四角を並べる（Instant Meshes 方式。一部に三角形が混ざる）
  - 「格子状」: 格子に沿って並べる。左右対称にできる
  - ループの向きの指定（形に沿う）: ポリグループの境目に沿わせる、「ガイド線」ブラシで表面に引いた線の向きに並べる（ガイド線はパーツごとに保存・左右対称にも対応）
- **ポリペイント**: 頂点に色を塗る（ペイントブラシ・色見本・全体塗り）。細分化レベル・リメッシュ・リトポ・ブーリアン・ポリゴン削減に引き継がれ、OBJ（頂点カラー）と GLB に書き出し
- **ブーリアン**: 2つのパーツを「足す / くり抜く / 重なりだけ」で演算（ボクセル方式＋元の面への吸着でエッジを復元）
  - **ライブブーリアン**: 演算結果を軽い精度で表示し続け、どちらかのパーツをギズモで動かす・彫る・元に戻すと、すぐに結果が変わります。「確定」でリメッシュの細かさで作り直します
- **ポリゴン削減**: 形・色・マスクの境目を保ったまま三角形を減らす（meshoptimizer の簡略化）
- **UV 展開とテクスチャ焼き付け**: リトポした軽いパーツの UV を自動展開し、細かいパーツ（または同じパーツの最上位レベル）から法線マップと色を焼き付け。プレビュー表示、PNG 保存、GLB へのテクスチャ込み書き出し、OBJ への UV 書き出しに対応
- **形を写す（投影）**: 別のサブツールの表面に合わせる。リトポ → 細分化 → 投影で元の細部を写し取れる。「表示中のすべてのパーツ」を選ぶと、表示しているパーツ全部からまとめて写します（ProjectAll 風）
- **リメッシュ（`Ctrl+R`）**: ボクセルでポリゴンを均一に作り直す（DynaMesh 相当）。引き伸ばして荒れた所の修復、重なったパーツの合体（「表示中のパーツを合体してリメッシュ」）。細かさ・ならし・元の形への吸着を指定でき、作り直し後のポリゴン数を事前に表示。マスクも引き継ぎます
- **ブラシ（65種類・1〜9, 0キー。`B` で一覧から探して選ぶ）**
  - 盛る: スタンダード / クレイ / クレイ盛り / クレイチューブ（ストロークの向きに平らな帯を盛る・ClayTubes）/ 膨らませる / 風船（丸みを保って膨らむ）/ レイヤー（一定の高さで盛る）/ ブロブ（丸い玉）/ トゲ / 埋める（凹みだけ平らに埋める）/ 折り目（布の盛り上がった筋）/ 重力（下へ垂らす）/ 吸い付け（表示中の別のパーツの表面へ・ZProject）/ ノイズ（肌・岩のザラザラ）
  - 表面の模様: しわ / ウロコ / 布目 / 毛穴 / 縫い目（点線）/ レーキ
  - 整える: スムーズ / 強いスムーズ / 角を残すスムーズ / 流れのスムーズ（ストロークの向きだけ）/ 谷をならす / 尾根をならす / そろえる（形を変えずにポリゴンをそろえる）/ くっきり（細部を強める）/ ポリッシュ（凹凸を削って磨く）/ 平面で磨く（塗り始めの面で削り、角を立てる・hPolish）/ 平らにする / プレーナー（硬い平面）/ トリム（出っ張りだけ削る）/ トリム（画面に平行な面で・TrimDynamic）/ モーフ（保存した形に戻す）
  - 彫る: シャープ溝（鋭いV字）/ 溝 / マレット（平らな底のへこみ）/ ひび / 切り込み / つまむ / 押し広げる / ねじる / ずらす
  - 形を動かす: ムーブ / ムーブ（奥まで：画面の奥まで貫いて裏側も一緒に）/ ムーブ（つながり：近くの離れた部分は動かない・Move Topological）/ ムーブ（弾性：体積を保ってつかむ・ねじる・拡大縮小・Kelvinlet）/ 引き伸ばし（ドラッグ方向へ伸ばして角・触手を作る）/ 曲げる / 大きさ（範囲だけ拡大縮小）/ ポーズ
  - 作る: チューブ / 並べる / ガイド線（自動リトポの向き）
  - マスク / 凹みマスク / マスク広げ・縮め / マスクぼかし / ペイント（ポリペイント）/ 凹みペイント / まだらペイント / 色を伸ばす / 色ぼかし / グループ塗り（塗った所を新しいポリグループに）
- **変形（デフォーマー）**: 選択中のパーツ全体を、軸（X/Y/Z）を選んで 曲げる・ねじる・先細り・伸ばす・膨らます・平らにする（マスクした所は動かない）
- **表面ノイズ（NoiseMaker 風）**: なめらか・岩肌・細胞（ウロコ・石畳）・細かい粒の4種類の模様で、表面を法線方向に凹凸にする。模様の大きさ・強さ・模様の番号を指定し、プレビューを見ながら調整してから適用（マスクした所は変わらない）
- **モーフターゲット**: 今の形を保存しておき、全体を戻す、または「モーフ」ブラシで塗った所だけ戻す。プロジェクトに保存
- **抜き出し（Extract）**: マスクした所を、厚みのある閉じた別パーツとして作る（服・鎧・ベルト）
- **クリップ（ClipCurve 風）**: 画面に線を引き、線の片側を線の位置で平らに切り落とす（Alt で反対側）
- **スライス（SliceCurve 風）**: 画面に線を引くと、線の位置にぴったり辺の輪を入れて、片側を新しいポリグループにする（形は変わらない）
- **パネル化（Panel Loops 風）**: ポリグループごとに、厚みとすき間のある別々の閉じた板にする（装甲・外装パネル）
- **下絵（参考画像）**: 正面・横・下に板として置く、または画面に重ねて表示（不透明度・大きさ調整）。画面に重ねた画像を、手前に見えている面へポリペイントとして投影（Spotlight 風）
- **配列（Array Mesh）**: パーツを指定した個数・向き・間隔で並べ、1つごとに回転・拡大縮小も可能
- **片側を写してつなぐ（Mirror & Weld 風）**: +X / −X の片側を反対側に写し、左右対称な1つのメッシュに作り直す
- **グループごとに分ける**: ポリグループごとに別のサブツールにする
- **凹みに色を塗る**: 溝やしわなど凹んだ所に、今のペイント色を塗る
- **毛（FiberMesh 風）**: マスクした所から毛（髪・毛皮・草）を生やして新しいサブツールにする。本数・長さ・ばらつき・重力・向き・太さを指定、根元の色を引き継ぐ
- **ターンテーブル動画**: 今の視点からモデルを1周させた動画を WebM で書き出し
- **つながりに沿ったマスク**: マスクブラシが、近くにあっても離れている部分（隣の指など）に付かない
- **色からポリグループ**: ポリペイントの色ごとにグループを作成
- **スプレー**: ストロークで位置・大きさ・向きを散らして塗る
- **文字・画像から立体（Text3D / Shadowbox 風）**: 文字やロゴ・シルエット画像を厚みのある立体にする（看板・ネームプレート・エンブレム）
- **ポーズ（Transpose 風）**: マスクしていない所を、クリックした関節を中心にドラッグで回す（腕・首・しっぽの角度を変える）
- **中を空ける（3Dプリント用）**: 壁の厚さを mm で指定して中を空洞にし、材料を節約
- **印刷サイズの表示**: 画面下に、STL の高さ設定で書き出したときの幅×奥行き×高さ（mm）を表示
- **高さ（ディスプレイスメント）マップ**: 焼き付けで法線マップ・色に加えて高さマップも作成し、PNG で保存
- **スポイト・色でマスク**: モデルから塗る色を取る、今の色に近い所をマスクする
- **視点の切り替え**: 正面・右・上・後ろにワンクリックで向ける
- **パーツに結合（IMM 風）**: チューブ・並べるで作った形を、新しいサブツールではなく選択中のパーツに結合
- **ポリゴンをそろえる**: 形を変えずにポリゴンの大きさを均一にする（ダイナミック細分化やムーブの後に）
- **修復**: 穴を埋める・本体から離れた小さな破片を削除・裏返った面の向きを直す（スキャンデータや 3D プリント前に）
- **3D プリントの確認**: オーバーハング（45° より下向き＝サポートが必要な所）を赤く表示、2点の距離を mm で計測
- **出っ張りをマスク**: 尾根やこぶなど出っ張った所をマスク（凹みマスクの逆）
- **ブラシの設定を保存**: ブラシ・サイズ・強さ・アルファなどの組み合わせに名前を付けて保存し、いつでも呼び出す
- **表示の設定**: 画角、光の向きと強さ、背景（暗い・グレー・明るい・青・黒）、元に戻せる回数（5〜200）
- **ZSphere**: 球をドラッグで引き出してつなぎ、人や動物の骨組みを作ってから、なめらかにつながった1つのメッシュに変換（左右対称・大きさ変更・移動・削除・元に戻す）
- **チューブ・並べる（CurveTube / IMM 風）**: モデルの表面をなぞった線に沿って、チューブ（ロープ・ホース・ツノ）や、球（数珠・鋲）・チェーン・トゲ・立方体を並べたパーツを新しいサブツールとして作成。太さ・先細り・間隔を指定可能
- **ダイナミック細分化（Sculptris Pro 風）**: 塗った所だけ自動でポリゴンを細かくしながら造形。細かさは画面上の三角形の大きさ（px）で指定
- **マテリアル（MatCap）**: 標準のライト表示に加えて、赤いワックス・グレー粘土・青い粘土・肌・白磁・翡翠・黒い樹脂・金・クローム・ブロンズ・トゥーンの11種類
- **マスク**: 背景で `Ctrl`+ドラッグの投げ縄／四角マスク（`Ctrl+Alt` で解除、`Ctrl`+クリックで反転）、広げる・縮める・ぼかす・くっきり・凹みをマスク
- **ポリグループ**: つながり・面の向き・マスクから作成、色分け表示（`Shift+F`）。`Ctrl+Shift`+クリックでそのグループだけ表示（`+Alt` で隠す）、背景で `Ctrl+Shift`+ドラッグで囲んだ所だけ表示、隠した所の削除
- **レイヤー**: 造形をレイヤーに記録し、あとから強さ（−1〜2倍）の変更・一時的に消す・削除・確定ができる。プロジェクトに保存
- **レンダリング**: 今の視点で、床の影とアンビエントオクルージョン付きの画像を作って PNG で保存（最大3倍の大きさ・背景透明も可）
- **ブラシ設定（ブラシごとに記憶）**: 強さ、減衰カーブ（なめらか / とがり / 平ら / 直線 / ドーム）、ストローク（連続で塗る / ドラッグで配置 / スプレー / 1つを動かして置く（DragDot）/ 直線）、間隔、手ぶれ補正
  - **深さ（埋め込み）**: 盛る・彫るブラシは強さの倍率、平面を使うブラシ（クレイ・平らにする・トリムなど）は平面の高さを変える
  - **彫る向き**: 面の平均 / 頂点ごとの法線 / 画面の奥行き / X・Y・Z 軸
  - **自動マスク**: 塗り始めのポリグループだけに効かせる、凹んだ所だけ・出っ張った所だけに効かせる
  - 筆圧でサイズも変える、ズームしてもモデル上の大きさを保つ
  - **ブラシの書き出し・読み込み**: 全ブラシの設定と保存した設定を `.bpbrush` ファイルにして、別の PC と共有
- **アルファ（ブラシの型）**: 四角・リング・星・ノイズ・粒・ひび割れ・ウロコ・しわ・布目を内蔵。PNG / JPG 画像から追加可能（ボタン or ビューにドラッグ＆ドロップ）。反転、ストロークの向きに回転、カーソル上にプレビュー表示
- **ドラッグで配置**: クリックした場所から、ドラッグした大きさと向きでアルファを1回スタンプ
- **修飾キー**: `Shift` スムーズ、`Ctrl` マスク、`Alt` 反転、`[` `]` ブラシサイズ
- **表示**: 左右対称（`X`）、ワイヤーフレーム（`W`）、全体表示（`F`）、全画面（`F11`）、ペンタブレット筆圧対応
- **ワンクリック処理**: 細分化（`Ctrl+D`）、全体スムーズ、左右対称化、中央に配置、マスク反転／解除
- **書き出し**: OBJ / FBX（Blender・Maya・Unity・Unreal 用。四角ポリゴン・UV・頂点カラー・クリースをそのまま）/ GLB（ゲーム用・パーツごとに分割）/ STL（3Dプリント用・全パーツを1つに・Z軸上向き・底面Z=0・高さmm指定）。表示中のサブツールが対象
- **ディスプレイスメント（EXR・32bit）**: UV のあるレベルから一番上の細分化レベルまでの細部を、ディスプレイスメントマップ（法線方向の距離）またはベクターディスプレイスメントマップ（接空間 X=U・Y=V・Z=法線）として書き出し。レベルのつながりから正確に写すので、レイが届かない所や折り返した形も崩れません。基準の面は「なめらか（細分化した面）」か「平ら」
- **開く**: .bpp / OBJ / STL / FBX / GLB / glTF（`Ctrl+O`・ドラッグ＆ドロップ・起動時の引数）。何も作業していなければOBJ/STLはそのまま開き、作業中ならサブツールとして追加
- 作業内容は自動保存され、次回起動時に復元（ディスクに少しずつ書き込むので、数千万ポリゴンでも保存中に固まらず、彫っている間は保存を待ちます。書き込み途中で落ちても前回の保存は壊れません）。大きなモデルの復元中は、読み込みの進み具合を表示

## 開発・自分でビルドする

**Windows で手軽に起動する**: リポジトリのフォルダにある `BoardPainter.bat` をダブルクリックすると、初回だけ必要なものを自動でインストールしてからアプリを起動します（Node.js 20 以上が必要。初回は数分かかります）。


Node.js 20 以上と C++ コンパイラ（Windows: Visual Studio の「C++ によるデスクトップ開発」、macOS: Xcode Command Line Tools、Linux: g++ と make）が必要です。コンパイラがない場合も起動はできますが、重い処理が JavaScript 版（低速）になります。

```bash
npm install          # 依存関係のインストール（three.js を src/vendor にコピーし、ネイティブモジュールをビルド）
npm run build:native # ネイティブモジュール（native/）だけをビルドし直す
npm start            # 開発用に起動
npm run dist:win     # Windows 用 exe（インストーラー + ポータブル）を dist/ に作成
npm run dist:mac     # macOS 用 dmg
npm run dist:linux   # Linux 用 AppImage
```

Windows のインストーラーは Windows 上でビルドしてください（Linux/macOS から作る場合は wine が必要）。`main` ブランチへの push で GitHub Actions が3つのOS向けに自動ビルドします。

**新しい版を公開するとき**: `package.json` の `version` を上げてから `v1.2.3` のようなタグを push する（または Actions の「Build desktop app」を手動実行して `release_tag` を入力する）と、ビルドされたファイルが Releases に自動で公開されます。

### 構成

| パス | 役割 |
| --- | --- |
| `electron/main.js` | アプリ本体（ウィンドウ・ファイルダイアログ・`app://` でUIを配信） |
| `electron/preload.js` | 画面側に公開するネイティブAPI（`window.bp`、ネイティブ処理は `window.bp.accel`） |
| `src/index.html` | 造形エンジンとUI |
| `src/remesh.js` | ボクセルリメッシュ・ブーリアン（内外判定・Surface Nets・元の形への吸着）と格子状の自動リトポ |
| `src/polyedit.js` | ポリゴン編集（押し出し・はめ込み・ループ挿入・面の削除・穴を閉じる・三角形を四角にまとめる） |
| `src/fieldretopo.js` | 形に沿った自動リトポ（方向場・位置場・四角ポリゴンの抽出） |
| `src/uv.js` | UV の自動展開（チャート分割・投影・詰め込み） |
| `src/bake.js` | 法線マップと色の焼き付け |
| `src/vdm.js` | 細分化レベルからのディスプレイスメント / ベクターディスプレイスメント |
| `src/fbx.js` | FBX（バイナリ 7.4）の書き出し |
| `src/exr.js` | OpenEXR（32bit 浮動小数）の書き出し |
| `src/hardsurface.js` | スライス（平面で辺の輪を入れる）・パネル化 |
| `src/project.js` | プロジェクトファイル（.bpp）の読み書き |
| `src/alphas.js` | 内蔵アルファの生成と画像からの読み込み |
| `src/zspheres.js` | ZSphere の球とつなぎ目を距離場で1つのなめらかなメッシュにする |
| `electron/native-worker.js` | ネイティブモジュールを別スレッドで動かし、画面からの依頼を受け付ける |
| `native/bp_native.cc` | ネイティブモジュール（C++・Node-API）: ボクセル化・Surface Nets・最近点探索による吸着となめらかにする処理、リトポの方向場・位置場、テクスチャ焼き付け（レイキャスト）、左右対称の頂点の対応付け |
| `scripts/vendor.js` | three.js などをオフライン用に `src/vendor/` へコピー |
| `scripts/build-native.js` | ネイティブモジュールを node-gyp でビルド（失敗時は JavaScript 版で動作） |
