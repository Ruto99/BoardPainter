サブツール

    クリックで選択、名前をダブルクリックで名前変更。ビュー上で別のパーツをダブルクリックしても切り替えられます。造形できるのは選択中のサブツールだけです。

    細分化レベル

    低いレベルで大きな形を直すと、高いレベルの細部はそのまま付いてきます。高いレベルで彫った内容も低いレベルに反映されます。リトポしたパーツを細分化して「形を写す」と、元の細部を写し取れます。

    ブラシ

    モデルの上でクリックし、ドラッグで大きさと向きを決めて押し付けます。ポリゴンが細かいほどきれいに出ます（細分化してから使ってください）。

    ポリゴン編集（ZModeler 風）

    低ポリゴンのパーツを、面と辺の単位で直接作り変えます。カーソルの下の対象が光り、クリック（押し出す・はめ込む・面を動かすはドラッグ）で実行します。背景のドラッグで視点は回せます。細分化レベルがないパーツで使えます（三角形のパーツは自動で四角にまとめます）。「なめらか表示」は細分化した仕上がりを低ポリゴンのまま見せます（ダイナミック細分化）。クリースした辺（水色）は細分化しても丸くなりません。

    レイヤー

      1.00

      赤い●が付いたレイヤーに、造形の結果が記録されます。あとから「強さ」で効き具合を変えたり、目のアイコンで一時的に消したりできます。細分化レベルを変えたり作り直したりすると、レイヤーは確定されます。

      ポリペイント（色塗り）

      ツールバーの「ペイント」ブラシで塗ります（Alt で元の色に戻す）。マスクした所には塗られません。色は細分化レベル・リメッシュ・リトポにも引き継がれ、OBJ（頂点カラー）と GLB に書き出されます。

      アルファ（ブラシの型）

      白い所ほど強く効きます。画像はビューにドラッグ＆ドロップでも追加できます。細かい模様は「細分化」でポリゴンを増やすときれいに出ます。

      ワンクリック処理

      マスクした部分はブラシや全体スムーズで変形しません。

      リメッシュ（作り直し）

      ポリゴンを均一な細かさで作り直します。引き伸ばして荒くなった所が直り、重なったパーツは1つにつながります。「細かさ」より細い部分は消えることがあります。

      自動リトポ（四角ポリゴン）

      10

      手作業のリトポ（トポロジー）

      表面に縦と横の線を引くと、線が交わった所が頂点、4本（3〜6本）の線で囲まれた所が面になります（ZBrush のトポロジーブラシ風）。左右対称がオンなら反対側にも線を引きます。オレンジの枠が、できる面の下書きです。

      選択中のパーツを、指定した数前後の四角ポリゴンで作り直した新しいサブツールを作ります（元のパーツは非表示で残ります）。四角ポリゴンは OBJ 書き出しでも四角のまま出力されます。「形に沿う」は面の向きに沿って四角を並べ、角やエッジに沿ってループを通します。左右対称にすると X=0 の面にループが乗り、左右がぴったり同じになります。「格子状」は流れが格子に沿う、より単純な方式です。

      ポリゴン削減

      25

      形・色・マスクの境目をできるだけ保ったまま三角形を減らします（ゲームや Web 用の軽量化向け）。

      Claude と連携（MCP）

      Claude Desktop や Claude Code から、チャットで頼んで BoardPainter を操作できます（形を置く・押し出す・面取り・ブーリアン・細分化・色・画面の確認・書き出し）。設定をコピーして Claude 側に追加し、ここで「許可」をオンにしてください。受け付けるのはこのパソコンの中からの接続だけです。書き出したファイルはホームの BoardPainterLink/exports に保存されます。

      Blender と連携（GoZ 風）

      Blender に付属のアドオン（boardpainter_link.py）を入れると、ボタン1つでパーツをやり取りできます（Blender の 3D ビューのサイドバー →「BoardPainter」タブ）。同じ名前で頂点の数が同じパーツが戻ってきたら、形だけを更新します（細分化レベル・色・マスクはそのまま）。受け渡しはホームの「BoardPainterLink」フォルダーで行います。

      ブーリアン（パーツ同士の演算）

      選択中のパーツと相手のパーツを演算した結果で、選択中のパーツを置き換えます（相手は非表示にします）。「正確」は角や平らな面をそのまま残します（穴のない閉じたパーツ同士で使えます。穴があるときは自動でボクセルにします）。「切り口を整える」は、切り口にできる細長い三角形だけを、まわりと同じ大きさの三角形に作り直します（角はそのまま・彫った細部はさわりません）。「ボクセル」はリメッシュの「細かさ」の精度で作り直します。

      オンにした時の「選択中のパーツ」と「相手のパーツ」の演算結果を、軽い精度で表示し続けます。どちらかをギズモで動かしたり彫ったりすると、すぐに結果が変わります。「確定」で、リメッシュの「細かさ」の精度で作り直します。

      UV とテクスチャ

      UV はまだありません

      45

      リトポした軽いパーツで使います：UV を展開 → 「焼き付け元」に元の細かいパーツ（または同じパーツの一番上の細分化レベル）を選んで焼き付け。細部と色がテクスチャになり、GLB にはテクスチャ込み、OBJ には UV 付きで書き出されます。ディスプレイスメント（EXR・32bit）は、UV のあるレベルから一番上の細分化レベルまでの細部を、レイを飛ばさずに正確に写します（単位はモデルの座標＝FBX / OBJ と同じ）。

      レンダリング（画像に書き出し）

      6

      今見ている角度で、影と隙間の陰影（アンビエントオクルージョン）を付けた高画質の画像を作ります。色はポリペイントの色を使います。

      書き出し

      表示中のサブツールを書き出します（OBJ/GLBはパーツごとに分かれ、STLは1つにまとまります）。STLはZ軸上向き・底面Z=0・指定の高さに自動で合わせます。OBJ/GLBは見たままの向き（Y軸上向き）で書き出します。

      プロジェクト

      .bpp ファイルに、すべてのサブツール・マスク・表示状態・カメラ位置を保存します。作業は自動でも保存され、次に起動したときに復元されます。
